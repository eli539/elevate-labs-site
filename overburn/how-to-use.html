How to use Overburnאיך משתמשים ב‑Overburn

Last updated: 26 November 2026עודכן לאחרונה: 26 בנובמבר 2026

  1. ConnectPaste an admin key from Anthropic or OpenAI. Only an organization admin can create one. How to create an admin key
  2. Let it learnIn the first 24 hours Overburn learns each key's normal pace.
  3. Get alertedYou get a push the moment a key spends faster than normal.
  4. Pause in one tapPause the key from the alert. Resume it in the app or in your provider's console.

Overburn tracks API spend only. Claude Pro/Max and ChatGPT Plus subscriptions are not included.

  1. מתחבריםמדביקים מפתח אדמין של Anthropic או OpenAI. רק אדמין של ארגון יכול ליצור מפתח כזה. איך יוצרים מפתח אדמין
  2. נותנים לה ללמודב‑24 השעות הראשונות Overburn לומדת את הקצב הרגיל של כל מפתח.
  3. מקבלים התראהברגע שמפתח מוציא מהר מהרגיל, מגיעה התראה לאייפון.
  4. עוצרים בלחיצהעוצרים את המפתח מההתראה. מפעילים מחדש באפליקציה או בקונסולה של הספק.

Overburn עוקבת אחרי הוצאה על ה‑API בלבד. מנויים כמו Claude Pro/Max או ChatGPT Plus אינם כלולים.
