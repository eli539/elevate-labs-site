Questions

How do I get an alert when my Claude API spend spikes?

Connect an Anthropic admin key in Overburn. It learns each key's normal pace and pushes an alert to your iPhone when a key spends much faster than usual.

Can I stop a runaway Anthropic or OpenAI API key from my phone?

With Anthropic, yes: Overburn sets the key to inactive in one tap and you can resume it any time. For OpenAI, Overburn alerts you and links you to the key in your dashboard.

Does Overburn track Claude Pro, Max or ChatGPT Plus?

No. It tracks pay-as-you-go API spend only.

Is it safe to give an app my admin key?

Your key is stored encrypted and used to read usage and cost. It changes a key's status only when you tap Pause. Delete your account and the key is erased. You can also revoke it in your provider's console at any time.

Can Overburn see my prompts or answers?

No. The usage and cost data providers share contains token counts and amounts, not the content of your requests.

שאלות

איך מקבלים התראה כשההוצאה על ה‑API של Claude קופצת?

מחברים מפתח אדמין של Anthropic ב‑Overburn. האפליקציה לומדת את הקצב הרגיל של כל מפתח ושולחת התראה לאייפון כשמפתח מוציא הרבה יותר מהרגיל.

אפשר לעצור מהטלפון מפתח API של Anthropic או OpenAI שיצא משליטה?

ב‑Anthropic כן: Overburn מעבירה את המפתח למצב לא פעיל בלחיצה אחת, ואפשר להפעיל אותו מחדש בכל רגע. ב‑OpenAI מקבלים התראה וקישור למפתח בדשבורד.

לא. היא עוקבת רק אחרי הוצאה על ה‑API.

זה בטוח לתת לאפליקציה מפתח אדמין?

לא. נתוני השימוש והעלות שהספקים משתפים כוללים כמויות טוקנים וסכומים, לא את תוכן הבקשות.
