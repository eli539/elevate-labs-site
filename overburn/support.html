How do I create an Anthropic admin key?

In the Claude Console, go to Settings → Admin keys. Only an organization admin can create one. The Admin API is not available for individual accounts, so set up an organization in Settings → Organization first.

How do I create an OpenAI admin key?

In the OpenAI platform, go to Settings → Organization → Admin keys. An organization owner can create one.

Why didn't I get an alert?

Providers publish usage data with a delay, so alerts are not instant to the minute. Also check that notifications are allowed for Overburn and that a Focus mode is not silencing it.

How do I resume a paused key?

Open the key in Overburn and tap Resume, or set it back to active in your provider's console.

Does Overburn track Claude Pro, Max or ChatGPT Plus?

No. It tracks pay-as-you-go API spend only.

How do I delete my data?

Settings → Delete my account. We also recommend revoking the admin key in your provider's console.

How do I manage Pro?

Upgrade in Settings; Restore purchases is on the upgrade screen. Manage or cancel your subscription; deleting the app does not cancel it.

יצירת קשר

כתבו ל‑info@elevate-il.net. בדרך כלל נענה תוך 2 ימי עסקים.

איך יוצרים מפתח אדמין ב‑Anthropic?

ב‑Claude Console נכנסים ל‑Settings ← Admin keys. רק אדמין של ארגון יכול ליצור מפתח. ה‑Admin API אינו זמין לחשבונות אישיים, ולכן קודם מגדירים ארגון ב‑Settings ← Organization.

איך יוצרים מפתח אדמין ב‑OpenAI?

בפלטפורמה של OpenAI נכנסים ל‑Settings ← Organization ← Admin keys. בעלים של ארגון יכול ליצור מפתח.

למה לא קיבלתי התראה?

הספקים מפרסמים נתוני שימוש באיחור מסוים, ולכן ההתראות אינן מיידיות עד הדקה. בדקו גם שההתראות מאושרות עבור Overburn ושמצב ״מיקוד״ אינו משתיק אותן.

איך מפעילים מחדש מפתח שנעצר?

פותחים את המפתח ב‑Overburn ולוחצים Resume, או מחזירים אותו למצב פעיל בקונסולה של הספק.

האם Overburn עוקבת אחרי Claude Pro, Max או ChatGPT Plus?

לא. היא עוקבת רק אחרי הוצאה על ה‑API.

איך מוחקים את המידע?

הגדרות ← מחיקת החשבון. מומלץ גם לבטל את מפתח האדמין בקונסולה של הספק.

איך מנהלים Pro?

משדרגים בהגדרות; שחזור רכישות נמצא במסך השדרוג. ניהול או ביטול מנוי; מחיקת האפליקציה אינה מבטלת מנוי.
